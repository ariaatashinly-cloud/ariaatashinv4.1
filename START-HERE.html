ARIA COMMERCE · 4.1

ariaatashin.

از ریپازیتوری تا فروش و تحویل کانفیگ، مرحله‌به‌مرحله.

این صفحه راهنماست؛ اطلاعات خصوصی ربات و درگاه را فقط داخل پنل خودت وارد کن.

ارتقا و GitHub

۱) از کاربران، فروشگاه و کل پوشه داده بکاپ خصوصی بگیر. برای کپی کامل پوشه داده، برنامه را متوقف کن. ۲) ZIP را باز کن و محتویات داخل پوشه ariaatashin را در ریشه همان ریپازیتوری فعلی جایگزین کن. web را هم کامل جایگزین کن. Dockerfile و go.mod باید مستقیم در ریشه باشند. ۳) همه فایل‌های تازه را اضافه کن؛ فقط main.go کافی نیست. فایل ZIP یا .env خصوصی را در GitHub عمومی قرار نده. ۴) در میزبان، همان Volume و مسیر داده، نام کاربری و رمز را حفظ کن. Build = Dockerfile، Linux amd64، پورت داخلی 8080 یا PORT میزبان، تعداد Replica = 1. ۵) Commit و Redeploy کن. اگر Volume قبلی حفظ شده باشد، کاربران و تنظیمات خوانده می‌شوند؛ نصب دوباره و ساخت دوباره کاربران لازم نیست.

فعال‌سازی ربات با گوشی

۱) در تلگرام @BotFather → /newbot → ساخت ربات و کپی توکن. ۲) چت ربات خودت → Start. ۳) پنل → ربات تلگرام → واردکردن توکن. فعلاً گزینه فعال‌کردن خاموش باشد. ۴) پیداکردن شناسهٔ من → حساب خودت را انتخاب کن. Chat ID باید شناسه مثبت همان حساب شخصی مدیر باشد. ۵) «فعال‌کردن خرید در تلگرام» را بزن؛ این دکمه توکن را بررسی و ربات و فروشگاه را فعال می‌کند. «بررسی اتصال و خرید» را بزن تا موارد باقی‌مانده معلوم شوند. اگر اتصال قبلی Webhook دارد، جایگزینی تأیید می‌خواهد. برای یک توکن فقط همین نمونه اجرا شود. ۶) فروشگاه و سفارش‌ها → تنظیمات فروش → فعال‌کردن فروشگاه. نام، پشتیبانی، بانک، شماره کارت، شماره حساب یا شبا و صاحب حساب خودت را وارد کن. ۷) پلن‌ها → پلن تازه → قیمت تومان، حجم، روز، الگو و مقصد. مقصد پیش‌فرض همین پنل است. ۸) درگاه‌ها → مرچنت حساب رسمی زرین‌پال / زیبال → فعال و ذخیره. دامنه عمومی باید HTTPS باشد. callback خودکار ساخته می‌شود؛ شماره حساب یا مرچنت بانکی خودکار ساخته نمی‌شود. ۹) کارگاه ربات → متن خوش‌آمد، تست یک بار برای هر حساب تلگرام و یادآوری اختیاری → ذخیره. ۱۰) در ربات /start بزن. خرید سرویس → پلن → تخفیف اختیاری → روش پرداخت. پس از تأیید، اشتراک و فایل متنی تمام کانفیگ‌ها ارسال می‌شوند.

روش‌های پرداخت

درگاه: تأیید سرور و تحویل خودکار. کارت / حساب: مشتری عکس یا شماره پیگیری می‌فرستد؛ مدیر پرداخت واقعی را بررسی و تأیید می‌کند؛ سپس تحویل خودکار است. کیف پول: شارژ تأییدشده → کسر یک‌باره برای همان سفارش → تحویل. Stars: مقدار مستقل در پلن؛ صورتحساب و پرداخت معتبر تلگرام.

چند پنل

پنل‌های مقصد → نوع ariaatashin یا 3x-ui یا Marzban کلاسیک، آدرس HTTPS، کلید API یا نام کاربری و رمز، اینباند / تگ‌ها → آزمایش اتصال → انتخاب مقصد در پلن. برای ربات دیگر، API و ربات دیگر را باز کن؛ رابط Marzban کلاسیک را در تنظیمات فروش فعال کن. آدرس همین پنل، نام api و API Key به‌عنوان رمز.

اگر پرداخت انجام شد ولی سرویس نیامد

دوباره پرداخت نکن. بررسی پرداخت را بزن؛ سفارش پرداخت‌شده و مبلغ ثبت‌شده حفظ می‌شوند. مدیر در سفارش‌ها وضعیت و بازیابی تحویل را بررسی کند. اگر شناسه درگاه بر اثر قطع شبکه دریافت نشده، مدیر آن را از داشبورد رسمی همان درگاه بگیرد و در جزئیات سفارش → بازیابی شناسه درگاه وارد کند. بدون تأیید معتبر سرور، اعتبار اضافه نمی‌شود.

محدودیت عملی

دیسک دائمی و یک Replica لازم‌اند؛ Restart دیسک موقتی را دائمی نمی‌کند. Cloud فقط الگوهای HTTP پشتیبانی‌شده را اجرا می‌کند؛ TUIC و Hysteria2 به VPS، پورت UDP مستقیم و TLS معتبر نیاز دارند. همه میزبان‌ها روی حساب واقعی آزمایش نشده‌اند. آزمون درگاه و Telegram Bot API با پاسخ‌های شبیه‌سازی‌شده انجام شده؛ تراکنش بانکی واقعی و ارسال به ربات شخصی تو هنوز انجام نشده‌اند. پس از واردکردن اطلاعات خودت، یک خرید کم‌مبلغ آزمایش کن. هسته این بسته 3x-ui 3.8.5 با هش ثابت است؛ هر نسخه آینده بدون بررسی سازگاری نصب نمی‌شود.
